## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nmedussuriya/Portfolio.git
```

### 2. Navigate to the project folder

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 📦 Available Scripts
